# La course de Zizou

Site d'une page qui passe en boucle la course de Zidane le long de la ligne de touche.

## Publier sur GitHub Pages
1. Pousser ces fichiers à la racine du dépôt.
2. Settings > Pages > Source : "Deploy from a branch", branche `main`, dossier `/ (root)`.
3. Le site est en ligne quelques minutes plus tard sur `https://<pseudo>.github.io/<nom-du-depot>/`.
